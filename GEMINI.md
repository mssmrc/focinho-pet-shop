# GEMINI.md

Este projeto usa um guia único para todos os agentes de IA. Leia **[AGENTS.md](./AGENTS.md)** antes de qualquer tarefa.

Resumo:

- Site demonstrativo, sem banco de dados. A sacola e o agendamento montam uma mensagem e abrem o WhatsApp do visitante. Não há pagamento online (exemplo do plano Catálogo).
- Textos e dados em `src/content/`; imagens em `src/content/images.json`.
- Não remova o crédito "Desenvolvido por Runa Web".
- Rode `npm run check` antes de terminar.
